Terminal sem medo

Comandos para preparar, executar e resolver problemas comuns na Pokédex da oficina.

Antes de começar: abra a pasta do projeto no VS Code e escolha Terminal → Novo Terminal. Os comandos foram preparados para Windows PowerShell. Copie e execute um comando por vez.

1. Abrir a pasta do projeto

No VS Code, abra a pasta onde ficará o arquivo main.py. Depois selecione Terminal → Novo Terminal.

Confira a pasta atual:

Get-Location

Liste os arquivos e confira se está na pasta certa:

dir

Se precisar entrar em outra pasta, use cd seguido do caminho dela. Exemplo:

cd "C:\Users\lucas\OneDrive\Desktop\teste"

Esse é apenas um exemplo. Cada aluno deve usar o caminho da própria pasta. Não copie um caminho que exista somente no computador do professor.

2. Conferir se o Python está instalado

Antes de criar o ambiente, verifique se o terminal reconhece o Python:

py --version

Se esse comando não funcionar, tente:

python --version

Se aparecer algo como Python 3.x.x, o comando foi reconhecido.

Se aparecer “Python não foi encontrado”: instale o Python para Windows pelo site oficial python.org/downloads. Durante a instalação, marque Add Python to PATH, se essa opção aparecer. Depois feche e abra novamente o terminal e teste o comando outra vez.

3. Criar o ambiente virtual

O ambiente virtual guarda as bibliotecas deste projeto separadas de outros projetos. Execute este comando na pasta do projeto:

py -m venv .venv

Se o comando py não funcionar, tente:

python -m venv .venv

Após alguns segundos, deverá aparecer a pasta .venv no projeto. Ela pode ficar oculta dependendo das configurações do Explorer.

Você normalmente cria o ambiente uma vez por projeto. Se a pasta .venv já existir, não precisa recriá-la: passe para a ativação.

Se aparecer um erro ao criar

  • Confira se está na pasta correta usando Get-Location.
  • Confira se o Python está instalado com py --version ou python --version.
  • Se houver uma pasta .venv incompleta ou com erro, não a apague sem confirmar que não contém nada importante; peça ajuda ao professor para recriá-la.

4. Ativar o ambiente virtual

Com a pasta .venv criada dentro do projeto, execute no PowerShell:

.\.venv\Scripts\Activate.ps1

Quando ativado, normalmente aparece (.venv) no início da linha do terminal.

Erro: o comando não é reconhecido ou o arquivo não existe

Isso geralmente significa que a pasta .venv não foi criada nessa pasta, ou que o terminal está em outro diretório.

  1. Execute Get-Location e confira a pasta atual.
  2. Execute dir e veja se a pasta .venv aparece.
  3. Se ela não existir, volte à etapa 3 e crie o ambiente na pasta do projeto.

Erro: a execução de scripts foi desabilitada

Se o PowerShell mostrar uma mensagem dizendo que não pode executar scripts, você pode usar o Prompt de Comando (CMD) no terminal do VS Code e executar:

.venv\Scripts\activate.bat

No VS Code, use a seta ao lado do botão de novo terminal e escolha Command Prompt/CMD. Não altere a política de segurança do computador sem orientação do professor ou responsável técnico.

Como sair do ambiente virtual

deactivate

Esse comando desativa o ambiente. Para trabalhar no projeto novamente, basta ativá-lo outra vez.

3. Instalar as bibliotecas

Confira a versão do Python:

python --version

Instale o Flet (biblioteca usada para criar a interface gráfica):

python -m pip install flet

Depois, instale as outras dependências usadas pelo projeto:

python -m pip install requests flet-desktop
  • Flet: cria a interface gráfica.
  • Requests: faz requisições para buscar dados da PokéAPI.
  • Flet Desktop: componente necessário para executar a janela desktop em algumas instalações.

A instalação geralmente só precisa ser feita uma vez por ambiente virtual. É preciso estar conectado à internet.

4. Executar a Pokédex

Com o terminal na pasta que contém main.py e o ambiente virtual ativo, execute:

python main.py

Se funcionar, a janela da Pokédex será aberta. Deixe o terminal aberto enquanto usa o programa.

5. Erros comuns e como resolver

Erro de biblioteca

ModuleNotFoundError: No module named 'requests'

O Python não encontrou a biblioteca Requests no ambiente ativo. Ative o ambiente virtual e execute:

python -m pip install requests
Erro de biblioteca

ModuleNotFoundError: No module named 'flet_desktop'

Instale o componente desktop do Flet no ambiente virtual:

python -m pip install flet-desktop
Erro de versão do Flet

module 'flet' has no attribute 'ImageFit'

Esse erro foi resolvido nesta versão do projeto usando a referência compatível com o código atual:

fit=ft.BoxFit.CONTAIN,

Atenção: este é um trecho de Python, não um comando para digitar no terminal. Abra o main.py e confira a linha indicada no erro.

Erro de versão do Flet

module 'flet.controls.padding' has no attribute 'symmetric'

Na versão do código usada na oficina, o padding simétrico fica assim:

ft.Padding.symmetric(horizontal=18, vertical=8)

Para um padding com lados definidos individualmente, use por exemplo:

ft.Padding(left=10, top=5, right=10, bottom=0)

São trechos de código para editar no main.py, não comandos de terminal. Preserve os valores que o layout precisar.

Erro de versão do Flet

module 'flet.controls.alignment' has no attribute 'center'

Para centralizar um controle, no código desta oficina foi usado:

alignment=ft.Alignment(0, 0),

Edite a linha indicada pelo traceback. Não cole esse trecho sozinho no terminal.

Erro de sintaxe

SyntaxError: invalid syntax. Perhaps you forgot a comma?

Normalmente indica que há um erro de escrita no arquivo Python, muitas vezes uma vírgula ausente entre argumentos.

  1. Abra o main.py no VS Code.
  2. Vá para a linha indicada no erro.
  3. Confira a linha anterior e a seguinte. Se um argumento continuar na linha seguinte, normalmente precisa de uma vírgula no final.
  4. Salve com Ctrl + S e execute novamente.

Não adicione vírgulas automaticamente em todo lugar: confira o contexto para não criar outro erro.

A janela abre, mas os Pokémon não carregam

Mensagem sobre conexão ou erro da API

A Pokédex busca dados pela internet. Confira a conexão e tente executar novamente:

python main.py

Se continuar falhando, leia a mensagem de erro que aparece no terminal. A API pode estar temporariamente indisponível, ou a rede pode estar bloqueando a conexão.

O arquivo não é encontrado

can't open file 'main.py'

O terminal provavelmente está na pasta errada ou o arquivo tem outro nome.

Get-Location
dir

Use cd para entrar na pasta correta e confirme que o arquivo se chama exatamente main.py.

Importante: nem todo erro se resolve digitando um comando no terminal. Mensagens como SyntaxError ou erros de atributos do Flet normalmente exigem editar o arquivo main.py. Leia sempre o traceback e confira o número da linha.

7. Fluxo rápido para os alunos

  1. Abrir no VS Code a pasta do projeto que contém (ou conterá) o main.py.
  2. Abrir Terminal → Novo Terminal.
  3. Conferir a pasta com Get-Location e os arquivos com dir.
  4. Conferir o Python com py --version ou python --version.
  5. Criar o ambiente, uma vez, com py -m venv .venv (ou python -m venv .venv).
  6. Ativar com .\.venv\Scripts\Activate.ps1.
  7. Instalar o Flet com python -m pip install flet e as dependências com python -m pip install requests flet-desktop.
  8. Executar com python main.py.
  9. Se houver erro, ler a mensagem completa e conferir a linha indicada antes de alterar o código.
